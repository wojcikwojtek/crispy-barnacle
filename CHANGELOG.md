## [1.0.0] - Initial Release

### Added
- Backend API with ASP.NET Core Minimal APIs
  - Weather forecast endpoint
  - Product management (CRUD)
  - User management with validation
  - Order processing with status transitions
  - Contact form submission
- Frontend Blazor Server application
  - Weather forecast display
  - Contact form with validation
- OpenAPI/Swagger documentation with Scalar UI
- In-memory data storage for demonstration
- Development container configuration
- VS Code launch configurations
- .NET 9.0 support

### Features
- ✅ RESTful API endpoints
- ✅ Interactive API documentation (Scalar)
- ✅ Blazor Server UI with SignalR
- ✅ Form validation (client and server-side)
- ✅ DTO pattern for API responses
- ✅ Business logic validation
- ✅ Order status workflow management
- ✅ Responsive Bootstrap UI

### Technical Highlights
- .NET 9.0
- C# 13 with nullable reference types
- Minimal API pattern
- Blazor Server
- OpenAPI/Swagger
- Scalar UI for API documentation
